# Расчёт стоимости доставки

Доступны тарифы `courier`, `pickup` и `express`. Стоимость складывается из базовой
цены, доплаты за расстояние и вес. Цены указаны в копейках, вес в граммах,
расстояние в километрах. Неполный килограмм оплачивается как целый.

Вес и расстояние должны быть положительными. Максимальная дистанция для
`courier` составляет 100 км, для `pickup` 50 км, для `express` 300 км.
Ошибки расчёта содержат номер заказа, тариф и исходную причину.
Причину можно проверить через `errors.Is`, а контекст получить через `errors.As`.

Команды выполняются из папки `Bonus2`, рядом с `go.mod`:

```bash
go test ./...
go test -cover ./...
go test -race ./...
go vet ./...
go build ./... 
gofmt -w .
```

Зависимости пакетов: `service -> model`, `repository -> service`.
В `model` описан заказ. В `service` находятся тарифы, ошибки и калькулятор.
В `repository` хранится набор тарифов. Калькулятор получает хранилище через
интерфейс `TariffRepository`, поэтому пакет `service` не импортирует `repository`.

Покрытие бизнес-логики в пакете `service`: 100%. Покрытие `repository`: 100%.
В тестах проверяются все тарифы, округление веса, границы расстояния,
ошибочные данные, поиск тарифа и сохранение причины ошибки.
