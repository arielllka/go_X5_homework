# HW3: сервис уведомлений

Учебная рассылка через email, push и SMS с историей сообщений, проверкой настроек,
обёртками ошибок и продолжением рассылки после паники отдельного канала.

Требуется Go 1.22 или новее. Из корня репозитория:

```bash
cd HW3
go run ./cmd/notify
go test ./...
go build ./...
go vet ./...
```

Программа показывает успешную отправку, пустой текст, отсутствие настройки
и отправку через исправные push и SMS после `BrokenNotifier`.
Дополнительный канал `SMSNotifier` работает с обоими диспетчерами через `Notifier`;
менять диспетчеры для его добавления не потребовалось.
Описание результатов и обработки ошибок: [my_work.md](homework/my_work.md).

Условия: [практика](practice/README.md), [домашняя работа](homework/README.md).
