# Практика занятия 8

Команды выполняются из папки `HW6`, рядом с `go.mod`.

```bash
go mod download
go run .
```

Во втором терминале:

```bash
curl -i http://127.0.0.1:8080/health
```

В ответ должно прийти `200 OK` и `{"status":"ok"}`. Заказ можно создать через
`POST /orders`, а получить через `GET /orders/{id}`.

Для запуска тестов:

```bash
go test ./...
go test -race ./...
```

Условие практики находится в `TASKS.md`, домашней работы — в `HOMEWORK.md`.
Заказы хранятся в памяти и после перезапуска пропадают. Для тестов отдельно запускать его не нужно.
